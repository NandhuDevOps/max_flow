Ex 6 – Maximum flow in a traffic network

Edit the road network, pick the entry and destination junctions, and get the maximum throughput, the bottleneck roads, road utilisation and what-if results. Then test how Edmonds-Karp scales on grid road networks.

Aim

To compute the maximum traffic flow and the bottleneck (minimum cut) roads of a city road network using the Edmonds-Karp algorithm and to analyse what-if scenarios.

1. Start with flow f = 0 on every road. 2. BFS from the source over roads with residual capacity c - f > 0 (shortest augmenting path). 3. If the destination is not reached, stop. 4. Bottleneck b = smallest residual on the path; add b to f along the path, subtract b on reverse edges. 5. Repeat. Max flow = sum of all b. 6. Min cut = roads from the set S reachable from the source in the final residual graph to the rest.

Result

Edmonds-Karp finds the maximum throughput using shortest augmenting paths, and the minimum cut read from the final residual graph has the same capacity as the flow, which verifies the max-flow min-cut theorem. Only widening roads in the minimum cut raises throughput; upgrading roads with spare capacity does not.
